# Praktikum 7 – Encapsulation

Folder ini berisi source code praktikum Pemrograman Berorientasi Objek (PPBO) tentang konsep encapsulation dalam Java.

Materi meliputi class dan object, getter, setter dengan validasi, serta penerapan encapsulation pada studi kasus rekening bank.

Source code berada di folder `src`. Riwayat commit setiap tahap praktikum dipertahankan untuk menunjukkan proses pengerjaan.
